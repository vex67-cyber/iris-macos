# 明目 · Iris —— Windows 移植规格书

> 目标：在 Windows 10 / 11 上实现一个**行为与 macOS 版逐条对齐**的护眼提醒应用。
> 本文档不含 macOS 代码，只描述「做什么」与「怎么做」，任何技术栈都可照着实现。
>
> 附带的 `port/windows/` 目录里有一份 **C# 调度器参考实现**（含等价单元测试），可直接拷进 .NET 工程。

---

## 0. 定位与范围

| | |
|---|---|
| **是什么** | 常驻托盘的护眼提醒器：20-20-20 双周期提醒 + 全屏休息浮层 + 休息壁纸 + 本地统计 |
| **不是什么** | 不是 macOS 版的代码移植（两者不共享代码）；不追求 UI 像素级一致，追求**行为一致 + 同一套设计语言** |
| **必须做到** | 空闲不打扰、全屏不打扰、随时可推迟/跳过、数据只存本机、不需要管理员权限 |
| **明确不做** | 联网账号、云同步、遥测、订阅 |

## 1. 技术选型建议

| 方案 | 评价 |
|---|---|
| **C# / .NET 8 + WPF**（推荐） | 托盘（`H.NotifyIcon` 或 Win32 `Shell_NotifyIcon`）、全屏无边框窗口、动画都最省事；自绘控件成熟；单文件发布 ~60 MB |
| C# / .NET 8 + WinUI 3 | 视觉更现代，但托盘需第三方库、全屏置顶窗口偶发焦点问题、打包需 MSIX |
| Electron / Tauri | 开发快，但内存 150 MB+ 起步，与「轻量常驻」的目标冲突 |
| Python + tkinter | 只能做最小可用版，全屏浮层与动画观感差距大 |

**打包分发**：`dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true`，附一个 `install.ps1`（复制到 `%LOCALAPPDATA%\Programs\Mingmu` + 创建开始菜单快捷方式 + 可选注册开机自启）。

## 3. 调度器（核心，必须逐条对齐）

### 3.1 状态与时间

```
Phase = Working | Breaking(kind) | Paused(reason)
kind  = Micro | Long
reason = Manual(until?) | Disabled
```

**铁律：所有时间判断用「绝对时刻」而非累加计数。** 每 500 ms 心跳一次，比较 `now >= nextMicroAt`。
这样系统睡眠、卡顿、时钟跳变都不会让计时漂移。

```
nextMicroAt : DateTime   // 下次微休息的绝对时刻
nextLongAt  : DateTime   // 下次长休息的绝对时刻
breakStartedAt / breakEndsAt : DateTime?
now : DateTime           // 心跳发布的时间戳，UI 全部基于它刷新
consecutivePostpones : int
```

### 3.2 心跳逻辑（伪代码，与参考实现一致）

```
tick(now):
  now = clock.now
  若 remindersEnabled == false → phase = Paused(Disabled); return
  若 phase == Paused(Disabled) 且已重新开启 → 从当前时刻重排一整轮

  若 phase == Paused(Manual(until)) 且 until != null 且 now >= until → Resume()
  若 phase == Breaking:
      若 锁屏或睡眠 → 静默结束（记为 completed）
      若 now >= breakEndsAt → 结束（completed）
      return

  // —— 工作中 ——
  若 锁屏或睡眠            → markAway()                    // 不弹提醒
  若 空闲 >= idleThreshold → markAway(now - idle)          // 视为已休息

  若 now >= nextMicroAt 且 长休息在 90 秒内即将到点 → 把这次微休息并入长休息

  longDue  = longEnabled 且 now >= nextLongAt
  microDue = now >= nextMicroAt
  若 longDue 或 microDue:
      kind = longDue ? Long : Micro
      若 deferFullscreen 且 检测到全屏:
          逾期超过「一个完整周期」→ 直接重排到 now + 间隔；否则 return（等退出全屏）
      beginBreak(kind, now); return

  若 previewEnabled:
      提前量 = (kind == Long) ? 30s : 10s
      若 0 < 到点剩余 <= 提前量 且 该时刻尚未预告过 → 触发预告回调
```

### 3.3 休息的开始与结束

```
beginBreak(kind, now):
  时长 = (kind == Micro) ? microDuration : longDuration
  phase = Breaking(kind); breakStartedAt = now; breakEndsAt = now + 时长
  触发 onBreakStart(kind) → 显示浮层 + 播放开始音

finishBreak(outcome):
  outcome == Completed:
      记入统计（kind, 真正休息的秒数 = min(实际时长, 计划时长)）
      consecutivePostpones = 0
  outcome == Skipped:   记入 skipped
  phase = Working
  kind == Micro → nextMicroAt = now + microInterval
  kind == Long  → nextMicroAt = now + microInterval; nextLongAt = now + longInterval
```

- **跳过**：给一整轮新周期（不惩罚，也不立刻再弹）
- **推迟**：`nextMicroAt（或 nextLongAt） += 5 分钟`，`consecutivePostpones += 1`；上限 2 次后推迟按钮置灰
- **立即休息**（用户主动）：按 `nextBreakKind` 立刻开始，不走预告

### 3.4 空闲 / 离开 / 归来

```
markAway(startedAt):  isAway = true; awayStartedAt = startedAt

handleReturn():
  离开时长 = now - awayStartedAt
  若 未启用空闲重置 或 离开 < idleThreshold → return
  nextMicroAt = now + microInterval
  若 离开 >= max(longDuration, 5 分钟) → nextLongAt = now + longInterval
  触发 onReturnFromAway(离开时长)    // 顶部问候胶囊
```

**要点**：回来时给一整轮新周期，**绝不"补罚"**（这是用户最反感的行为）。

### 3.5 暂停 / 恢复

```
Pause(until?):  phase = Paused(Manual(until)); pausedAt = now
Resume():       平移量 = now - pausedAt; nextMicroAt += 平移量; nextLongAt += 平移量; phase = Working
PauseUntilTomorrow(): 明天 08:30
```

## 4. Windows 平台技术映射

| 能力 | macOS 用的 API | Windows 对应做法 | 注意 |
|---|---|---|---|
| 托盘图标 | `NSStatusItem` | Win32 `Shell_NotifyIcon`（或包装库 `H.NotifyIcon`） | 图标需提供 16/20/24/32 多尺寸；**动态倒计时文字**建议直接改托盘图标位图或 `szTip`（Windows 托盘不支持在图标旁显示文字） |
| 托盘弹窗 | `NSPopover` | 无边框 `Window`（`WindowStyle=None`、`Topmost`、`ShowInTaskbar=false`） | 失焦即关闭；工作区边缘自动收边 |
| 全屏浮层 | `NSPanel(.nonactivatingPanel)` + `level = .screenSaver` | 每显示器一个无边框窗口 + `WS_EX_TOOLWINDOW \| WS_EX_NOACTIVATE` + `SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)` | 必须覆盖任务栏：窗口矩形取 `EnumDisplayMonitors` 的**物理像素**全尺寸；不抢焦点才能不打断输入 |
| 空闲检测 | `CGEventSource.secondsSinceLastEventType` | `GetLastInputInfo()` → `(GetTickCount64() - lastInput)/1000` | 毫秒精度，无需权限 |
| 锁屏 / 睡眠 | `NSWorkspace` 通知 | `Microsoft.Win32.SystemEvents.SessionSwitch`（锁屏）+ `PowerModeChanged`（睡眠/唤醒） | 两者都在 `Microsoft.Win32` 里，无需额外依赖 |
| 全屏应用检测 | `CGWindowListCopyWindowInfo` + 屏幕比对 | `SHQueryUserNotificationState()`：返回 `QUNS_RUNNING_D3D_FULL_SCREEN` / `QUNS_PRESENTATION_MODE` / `QUNS_BUSY` 视为全屏；再兜底比对前台窗口矩形与显示器矩形 | 比枚举窗口更可靠，且不用遍历桌面 |
| 全局快捷键 | Carbon `RegisterEventHotKey` | `RegisterHotKey`（Win32） | 建议 `Ctrl+Alt+B` / `Ctrl+Alt+P`（macOS 用 `⌃⌥⌘B` / `⌃⌥⌘P`）；注册失败要能降级为「仅托盘菜单可用」 |
| 系统音效 | `NSSound`（/System/Library/Sounds） | `System.Media.SystemSounds.{Asterisk, Beep, Exclamation, Hand, Question}` 或 `PlaySound` 播放 wav | Windows 可选项更少，给出 5 选 1 + 无 |
| 壁纸缓存目录 | `~/Library/Application Support/Iris` | `%LOCALAPPDATA%\Mingmu\`（`stats.json`、`Wallpapers\`） | 保持同样的目录结构，便于文档对照 |
| 开机自启 | `SMAppService` / LaunchAgent | 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | **HKCU 不需要管理员权限**；不需要时删除键值 |
| 系统通知 | `UNUserNotificationCenter` | Windows Toast（`AppNotificationBuilder` / 社区库） | 默认关闭；不授权也不影响使用 |
| 高 DPI | 自动 | 清单声明 Per-Monitor V2 DPI 感知 | 否则浮层在多显示器不同缩放下会错位 |

## 5. UI 规格

### 5.1 托盘弹窗（340 × 408 px）

```
┌──────────────────────────────────┐
│ [图标] 明目            ● 工作中   │   头部：品牌标记 22×22 + 名称 13.5 semibold
│                                  │         右侧状态胶囊（点 + 文字，11pt）
│            ╭───────╮             │
│            │ 12:34 │             │   环：直径 164，线宽 11，从 12 点顺时针
│            ╰───────╯             │       中心：倒计时 36pt rounded 等宽数字
│           距下次休息              │       下方 11pt 次要文字
│         👁 每 20 分钟一次微休息    │
│                                  │
│ [  👁 立即休息  ] [ ⏱ 推迟 5 分钟 ]│   主按钮 30 高、圆角 6、渐变填充
│                                  │
│ ──────────────────────────────── │
│ ┌今日休息┐┌休息时长┐┌连续达标┐    │   三个小卡片：11pt 标签 + 14.5pt 数值
│ │   8    ││ 7 分钟 ││   2    │    │
│ └────────┘└────────┘└────────┘    │
│ ⚙  📊  ⏸                     ⏻   │   底栏图标 28×24，悬停底色 8%
└──────────────────────────────────┘
```

- 环的进度 = **剩余比例**（1 → 0），工作中和休息中都一样
- 距下次休息 < 60 秒时环变琥珀色
- 休息中：胶囊显示「微休息/长休息」，主按钮变为「推迟 / 跳过」
- 已暂停：环内换成暂停图标，显示「HH:mm 恢复」，主按钮「恢复提醒」
- 悬停背景：默认 `#00000008`，悬停 `#00000014`（深色模式对应白色透明度）
- **悬停时只改透明度，不要插入新控件**（否则相邻元素会跳动）

### 5.2 休息浮层（全屏）

| 元素 | 规格 |
|---|---|
| 背景 | 垂直渐变 `#0A1419 → #0D1C24 → #08100F`（微休息）/ `#0D0F21 → #121733 → #0A0D1A`（长休息）；若有壁纸则叠一层壁纸 + 黑色 62% 遮罩 |
| 中心光晕 | 直径 1150 的径向渐变（品牌色 26% → 5% → 透明），21 秒一次缓慢漂移（±84×±62），必须用 GPU 动画而不是每帧重绘 |
| 顶部标签 | 胶囊：图标 + 「微休息 · 看看远处」/「长休息 · 让眼睛放个假」，品牌色文字 + 12% 填充 |
| 倒计时环 | 微休息：直径 300、线宽 14；长休息：直径 330、线宽 4。**从 12 点顺时针**，弧长 = 剩余比例 |
| 中心数字 | 微休息 69pt rounded 等宽；「保持放松」12pt 45% 白 |
| 小贴士 | 16.5pt 72% 白，居中，每 8 秒换一条（文案见 §8） |
| 长休息引导 | 呼吸：直径 268 的圆在 0.66↔1.0 之间呼吸（4 秒吸、6 秒呼，周期 10 秒），中心显示「吸气/呼气」+ 剩余秒数；眼部运动：见 §5.3 |
| 结束剩余 | 「还有 4:32」13pt 45% 白 |
| 按钮 | 胶囊、34 高、白 8% 填充 + 13% 描边；「推迟 5 分钟」「跳过」；严格模式为长按按钮（按住时用珊瑚色填充进度，3 秒后生效） |
| 提示行 | 11.5pt 34% 白：「休息一下，对眼睛好一点」/「Esc 推迟 · ⌘. 跳过」 |
| 素材署名 | 左下角 10pt 30% 白，显示壁纸来源（如「摄影：X · Lorem Picsum」） |

**交互**：
- 浮层**不抢焦点**（用户可继续在原窗口打字）→ 按钮仍可点击
- `Esc` = 推迟 5 分钟；专注模式（可选项）下才接管键盘
- 操作按钮延迟 1.2 秒淡入，避免误触
- 多显示器：每块屏幕一个窗口，内容相同

### 5.3 眼部运动跟练（长休息）

以圆点轨迹引导，6 个动作循环，总时长 27.5 秒：

| # | 动作 | 提示文案 | 时长 | 轨迹 |
|---|---|---|---|---|
| 1 | 左右移动 | 跟着圆点，慢慢左右看 | 4.5 s | 水平正弦摆动（±33% 宽度） |
| 2 | 上下移动 | 抬头，低头，不要动头 | 4.5 s | 垂直正弦摆动（±32% 高度） |
| 3 | 画个圆 | 让眼球顺时针转一圈 | 5 s | 圆周运动（半径 30%/32%） |
| 4 | 对角线 | 左上、右下，交替看 | 4.5 s | 对角正弦摆动 |
| 5 | 用力眨眼 | 完整地眨 3 次 | 4 s | 眼睛图标纵向压扁 3 次 |
| 6 | 望向远方 | 看最远的地方，直到它变清晰 | 5 s | 圆点缩小 + 光环扩散淡出 |

## 12. 移植时最容易踩的坑

1. **浮层抢焦点**：Windows 上 `Topmost` 窗口默认会激活自己，导致用户正在打的字跑进浮层。必须 `WS_EX_NOACTIVATE` + `SetWindowPos(SWP_NOACTIVATE)`，并且不要调用 `Activate()`。
2. **任务栏没盖住**：窗口要用显示器的**物理像素**全矩形（含任务栏区域），高 DPI 下要按 `GetDpiForMonitor` 换算。
3. **每帧重绘全屏**：倒计时环一定要用 GPU 动画（WPF 的 `DoubleAnimation` / 合成层，或 WinUI 的 Composition API），**不要**每秒重建控件树——macOS 版在这里踩过坑（30fps 重绘整屏导致 10% CPU）。
4. **`GetLastInputInfo` 的坑**：它统计的是「本会话的输入」，锁屏后会一直增长 → 正好当作"离开"，符合预期；但要用 `GetTickCount64` 做差，注意 49.7 天回绕。
5. **提示音不要常驻音频线程**：播放器实例用完即释放（macOS 版有过音频线程空转 10% CPU 的问题）。
6. **壁纸大图解码**：不要下载 4K 再缩放，直接请求 1920×1080，且在后台线程做缩放。
7. **修改托盘图标文字**：Windows 托盘不支持图标旁文字，倒计时只在悬停提示与弹窗里显示。
